fix: add a validator that can actually see app.js, drop dead import

node --check app.js parses an ES module as CommonJS, throws on the first
import and stops - reporting success without ever reaching the body. A
stray comma in a ternary in saveChosenRep() therefore passed every
"syntax: clean" check I ran. check.js now parses browser files with
vm.SourceTextModule, keeps node --check for the CommonJS serverless
functions, and additionally parses each of the 142 top-level functions
in isolation so a broken one is named with its line number.

The validator proves itself before it reports anything: it plants a known
error and fails if that error is NOT caught. A validator that cannot
fail is worse than no validator.

Also removes the now-unused runTransaction import, left behind by the
Phase 5 deletion of the client-side rep race, and documents the
--check blind spot in README and ROADMAP so it is not rediscovered.
